# Image prompts: Tshehetso Consulting website

Sixteen real-looking photos for the site. Save each one in `assets/` with the exact filename below. The pages already point to these names, so every photo appears as soon as the file is added. Until then, a soft "Photo coming soon" tile shows.

**Use the same style line for every image** (paste it after each prompt):

> Photorealistic documentary photograph, natural window light, warm earthy tones (terracotta, sage green, cream), shallow depth of field, Black South African people, modest everyday clothing, calm and respectful mood, set in a simple Soweto home or a small private counselling room, no text, no logos, no watermarks.

**Size:** square 1:1 for the services (about 800×800). 16:10 landscape for the "What to expect" cards (about 1200×750). Save as WebP under 150 KB if you can.

**Faces:** where a prompt says *no faces*, frame hands, shoulders or backs only. This matters for sensitive topics such as abuse, HIV and substance use, so no one looks identifiable or labelled.
